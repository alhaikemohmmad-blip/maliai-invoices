MaliAI · تفريغ الفواتير لإكسل

بتسحب الفاتورة (صورة، PDF، Word، Excel، أو XML الفوترة) وبتنكتب بجدول إكسل خلال ثواني.

نزّل ملف الإضافة

بعدها ركّبها مرّة وحدة بس، بإحدى الطرق هاي:

إكسل على النت (الأسرع)

  1. افتح أيّ ملف إكسل على excel.cloud.microsoft.
  2. Home ← Add-ins ← More Settings.
  3. Upload My Add-in ← اختار الملف MaliAI.xml ← Upload.
  4. بيطلعلك زر تفريغ الفواتير بتبويب Home.

إكسل على الكمبيوتر

  1. حط MaliAI.xml بمجلّد، وشاركه: كليك يمين ← Properties ← Sharing ← Share. وانسخ مساره (مثل \\PC-NAME\MaliAI).
  2. بإكسل: File ← Options ← Trust Center ← Trust Center Settings ← Trusted Add-in Catalogs.
  3. الصق المسار بـ Catalog Url ← Add catalog ← علّم Show in Menu ← OK. سكّر إكسل وافتحه.
  4. Home ← Add-ins ← More Add-ins ← SHARED FOLDER ← MaliAI ← Add.

شركة عندها Microsoft 365

مدير الحسابات بيرفع الملف مرّة وحدة من Microsoft 365 admin center ← Settings ← Integrated apps ← Upload custom apps، وبتظهر الإضافة لحالها بإكسل عند كلّ الموظّفين اللي بيختارهم (ممكن تاخد لحدّ يوم).
